# LOST Timer — Chromecast edition

Самодостаточная версия таймера, в которой Chromecast заменяет второй монитор.

## Запуск

1. Распакуйте папку на любом компьютере и откройте `index.html` в Google Chrome.
2. В нижнем меню таймера нажмите **«📺 Открыть консоль Chromecast»**.
3. В открывшейся вкладке Chrome выберите **Трансляция → свой Chromecast → Транслировать вкладку**. Текущее устройство называется `Chromecast0299`.
4. Вернитесь на вкладку таймера. Вкладка консоли продолжит показываться на Chromecast.

В последние четыре минуты вводите `4 8 15 16 23 42` прямо с клавиатуры, оставаясь на вкладке таймера. Набранный текст отображается в терминале на Chromecast. `Backspace` исправляет ввод, `Enter` отправляет код.

Сервер, установка зависимостей и интернет для работы таймера не нужны. Chromecast и компьютер должны находиться в одной локальной сети.
