# LOST на AppKit / WKWebView

Целевая машина: Mac mini Late 2014 (Macmini7,1), Intel, macOS Monterey 12.7.6. Минимальная версия сборки — macOS 12.0; UI использует AppKit и публичные API WebKit. Сборка проверена штатным swiftc 5.7.2 на целевом Mac. Версия движка зависит от системного WebKit; проверка доступности WKWebView сама по себе не заменяет проверку HTML/CSS.

Два полноэкранных окна в одном приложении: таймер на `config.display`, терминал на другом дисплее. Borderless-окно терминала принимает клавиатурный фокус. Приложение отслеживает изменение дисплеев, повторяет загрузку после ошибки навигации или завершения WebContent, завершается при потере родительского ядра. Надзор ядра и автозапуск по-прежнему выполняет `com.exrector.lost`; отдельные процессы Node, WebContent и агента ИБП остаются частью станции.

## Сборка и установка

Из корня репозитория:

```sh
./script/build_and_run.sh --build-only   # сборка без остановки станции
python3 script/install_native.py        # установка, сохранение состояния и проверка готовности
# либо одной командой:
./script/build_and_run.sh
```

Требуются Command Line Tools, Node.js и уже установленные зависимости LOST. Для Mac mini сборка должна выполняться на нём; архитектура выбирается по `uname -m`, deployment target — 12.0. Переменная `LOST_BUILD_ARCH=x86_64` позволяет явно выбрать Intel при подходящем SDK. Сборка лежит в `native/dist/LOST.app`. Установщик заменяет корневой `LOST.app`, выставляет `renderer: "native"` в config.json и запускает прежнюю службу. Клик по приложению запускает эту же службу или переносимый `start.command`.

До изменения создаётся `.native-backups/<дата>-<id>/` с исходным приложением и конфигурацией. Текущее состояние `.state.json` не заменяется. При отсутствии готовых WebSocket-окон за 45 секунд установщик автоматически восстанавливает прежние приложение и конфигурацию. Ручной откат:

```sh
python3 script/install_native.py --restore .native-backups/<дата>-<id>
```

Для возврата к Chrome нужен backup, сделанный до первой установки native. Более поздние backup могут уже содержать native-приложение.

`renderer` без значения `native` оставляет запуск Chrome. Повторная установка не сбрасывает таймер. `Cmd+Q` и пункт выхода меню LOST завершают всю станцию штатно; аварийное завершение native host восстанавливает ядро. Перезапуск окон продолжает активный Live/Dev и паузу из состояния ядра.

## Диагностика

`/__health`: компоненты timer/terminal/display/ups и renderer. Логи — `~/Library/Logs/LOST/core.log` и `core-error.log`. `native-status.json` содержит PID владельца и размеры окон. Для временной разработки `LOST_NATIVE_DIAGNOSTICS=1` включает PNG-снимки окон, DOM-диагностику и беззвучную проверку MP3 раз в 10 секунд; в обычной службе флаг выключен.

WebKit Monterey потребовал явной установки размера шрифта на вложенных слоях `.lost-flipper` в конструкторе таймера: один родительский font-size оставлял дочерние цифры 16px. Явный размер сохраняет существующую геометрию и в Chrome.

Автоматизированная проверка установщика: `python3 -m unittest discover -s test -p 'test_native_installer.py'`. Скрипт сборки поддерживает `--verify`, `--logs`, `--telemetry`, `--debug` (lldb attach после установки).


## 2026-10-24 — доступ к рабочему столу

PF6 на Informer 213 передаёт F6 и теперь глобально переключает LOST ↔ рабочий стол. Оба окна скрываются через NSApplication.hide; Dock и верхнее меню освобождаются, отсчёт и ИБП продолжаются. Повторная PF6 возвращает окна и фокус терминала. Возврат также доступен через значок LOST в Dock; в меню терминала добавлен пункт РАБОЧИЙ СТОЛ. Нажатие не затрагивает паузу, Live/Dev и остаток. Перепрошивка клавиатуры не нужна; PF7–PF12 сохраняют управление мультимедиа. Глобальная F6 резервируется приложением на время его работы. Если регистрация недоступна, работает локальная F6 и возврат через Dock; это отмечается в логе.

В скрытом режиме восстановление страницы и изменение дисплеев не должны выводить окна вперёд. От автоповтора F6 защищает обработка отпускания. Поддерживается активность приложения без App Nap, native-status.json содержит desktopMode/hidden/globalPF6. Обработчик WKScriptMessageHandler слабый, доступ к рабочему столу из меню принимает только сообщение главного фрейма терминала.


Уточнение владельца 2026-10-24: PF6 используется только для скрытия обоих окон; возврат через основное LOST.app/значок Dock или переключение на приложение. Переключение по повторной PF6 отменено. При этой установке разрешён один новый цикл Live 108:00; `install_native.py --reset-live` делает его явно, сохраняя Dev и резервную копию прежнего состояния. Обычный запуск и установка без этого флага по-прежнему сохраняют состояния и паузы. Проверочные экземпляры не должны оставаться запущенными вместе с рабочей станцией.


## 2026-10-24 — финальные правила часов

Время принадлежит Node-ядру (cast-app/clock.js), а не WKWebView. Сворачивание PF6 не ставит его на паузу. Live продолжает отсчёт под Dev (`liveInDev=true`); пауза каждого режима независима. После перезапуска продолжается сохранённый остаток, без учёта времени выключения. Старые описания замораживания Live при Dev выше относятся к прежней реализации. Standalone HTML внутри архивной браузерной версии сохранён отдельно.


### Локальная отладка перед переносом на mini

`./script/build_and_run.sh --preview` собирает и открывает отдельный LOST Preview в двух обычных окнах на текущем Mac. Данные находятся в `.preview/`, HTTP слушает только `127.0.0.1:18765`; рабочая станция на mini, launchd, iMessage и системное устройство звука не изменяются. Путь можно задать через `LOST_PREVIEW_DIR`. Для готового Intel-бандла: `LOST_BUILD_ARCH=x86_64 ./script/build_and_run.sh --build-only`. Проверенный бандл вместе с изменёнными ресурсами переносится на mini и устанавливается существующим `script/install_native.py`, без повторной сборки на mini.


### Актуальная упаковка и первая установка

В Git включён полный проверенный корневой Intel-бандл LOST.app; native/dist и кэши сборки остаются локальными. Для новой установки нужны Node.js 20+, `(cd cast-app && npm ci)` и `python3 cast-app/install-service.py --root "$PWD"`. После этого LOST.app запускает ту же службу. Для обновления из исходников сначала выполняется сборка в native/dist, затем install_native.py; сам установщик не собирает бинарник. Сборка может выполняться на текущем Mac с LOST_BUILD_ARCH=x86_64; обязательная сборка на mini из исторического описания выше больше не требуется. PF6 только скрывает окна, возврат выполняется через Dock. Run в Codex запускает локальный --preview.
