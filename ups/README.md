# Энергоконтур LOST

Отдельный модуль для CyberPower CP900EPFCLCD через NUT на Keenetic: `192.168.1.1:3493`, устройство `ups0`.

## Экран и управление

Только `console.html`: рамка ниже на 28 px, под ней одна строка. Courier New / Courier / monospace совпадает со шрифтом ввода кода. Колонки имеют постоянное положение; нет мигания и звуков интерфейса.

`PWR` — EXT / RESERVE / UNKNOWN / LOST; `RSV` — заряд; `ENDURANCE` — приблизительная автономность по оценке самого ИБП; `BUS` — вход → выход. Значения не подменяются номинальными. OB — янтарный; OB с LB, зарядом ≤15% или оценкой ≤300 секунд — красный. После возвращения сети — зелёный. При ошибке связи/устаревании числа скрываются.

Меню: **M → ЭНЕРГОКОНТУР** или физическая клавиша **U** (работает с русской раскладкой). TAB / SHIFT+TAB, ENTER, ESC. Разделы: обзор, резерв, линия, устройство, драйвер, все данные. Неизвестные параметры производителя тоже отображаются. Основной таймер и его экран не изменяются.

Все 51 поле текущего устройства доступны для чтения. Семь настроек с подтверждением и проверкой обратным чтением: `battery.charge.low`, `battery.runtime.low`, `input.sensitivity`, `input.transfer.low/high`, `ups.delay.shutdown/start`. Также доступен звуковой сигнал. Отладочные параметры показаны только для чтения. Команд отключения нагрузки и питания в API модуля нет.

## Служба на Mac mini AK

Node 20: `~/.local/node/bin/node`; `~/LOST/ups/agent.js`; LaunchAgent `~/Library/LaunchAgents/com.exrector.lost-ups.plist`. Устанавливается `python3 ~/LOST/ups/install-user.py` без sudo, независимо от процесса таймера. Проверяет UPS каждые 5 секунд.

Настройки соединения и пароль хранятся **вне репозитория**, в `~/Library/Application Support/LOST UPS/connection.json`, права 600, каталог 700. В браузер пароль не передаётся. На Keenetic отдельный пользователь `lost-settings` с `actions=SET` и только `beeper.enable/disable`; исходный пользователь `nut` и монитор UGREEN сохранены. Сервер перечитывает авторизацию без перезапуска драйвера.

Агент слушает только `127.0.0.1:8766`; запросы принимаются от `http://localhost:8765` и `http://127.0.0.1:8765`. Запись требует JSON, заголовка `X-LOST-UPS: 1`, актуального ожидаемого значения и проверки допустимого диапазона. Для локального предпросмотра разрешён один дополнительный Origin через `LOST_UPS_PREVIEW_ORIGIN`. Удалённая консоль на другом компьютере не обращается к агенту Mac mini: строка будет показывать LOST.

`policy.js` и `/policy` резервируют настройки будущего автовыключения. По умолчанию оно выключено; включение отклоняется без действующей системной службы. **Этот модуль пока не выключает Mac.** Физические испытания отключением электричества не выполнялись.

## Проверка и откат

`node --test ups/test/*.test.js`: фрагментированный TCP, экранирование, отказы авторизации, таймауты, защита от вставки команд, диапазоны настроек, переходы OL/OB/LB и устаревшие данные. Проверка записи на реальном UPS выполняется повторной записью существующего `battery.runtime.low=300` и обратным чтением — рабочий порог не меняется.

Перед установкой сохраняется копия `console.html` и `cast-app/bridge.js` в `~/LOST-backups/ups-*`. Откат: восстановить эти два файла, выгрузить агент командой `launchctl bootout gui/$(id -u) ~/Library/LaunchAgents/com.exrector.lost-ups.plist`, перезагрузить только вкладку консоли. Основной процесс и вкладку таймера не требуется перезапускать.

`preview.html` и `preview.jpg` — первоначальный макет с условными цифрами, не диагностические данные.
