# LOST Cast — таймер на Chromecast, терминал на компьютере

Оригинальные `index.html`, `console.html`, `js/lost-timer.js` **не изменены**. Сервер отдаёт их с подмешанным
адаптером `bridge.js`, который заменяет `window.open/opener/postMessage` на WebSocket.

## Запуск
Двойной клик по `start.command` (или `node start.js`). Он:
1. поднимает локальный сервер (порт из `config.json`);
2. открывает таймер на Chromecast через DashCast (`cast.js`, чистый Node, без Python);
3. открывает окно терминала (Chrome `--app`, если он установлен, иначе браузер по умолчанию).

Остановка — Ctrl+C или закрыть окно Terminal. Chromecast указан в `config.json` по mDNS-имени `*.local` (IP не нужен).

## Устройство
- На ТВ виден только таймер: нижнее меню и Dev-панель скрыты CSS-ом (остаются в DOM).
- Весь интерфейс управления — в окне терминала: клик по `>:` раскрывает меню (Пауза, Live Mode, Dev Mode;
  в Dev Mode — таймеры, звук, сброс, иероглифы, проигрывание звуков). Клики уходят по мосту и превращаются в
  клики по скрытым элементам ТВ (белый список селекторов в `bridge.js`).
- jQuery отдаётся локально (`vendor/`), интернет таймеру не нужен.

## Грабли (выяснено эмпирически)
- Пространство имён DashCast — `urn:x-cast:com.madmod.dashcast`. `reload:false`, иначе страница перезагружается в цикле.
- Chromecast закрывает страницу, когда отправитель отключается: `cast.js` держит соединение с пульсом.
- Chromecast 1 (Chrome 70, 1280×720) тянет таймер и звук нормально.
- VPN: `catt scan` не находил устройство (много `utun`); прямое подключение по имени/IP работает.
- Кнопка «Open Console» нажимается моделью с повторами, пока `index.html` не навесит обработчик.

## Звук (переключатель в меню: Мак → ТВ → Выкл)
- По умолчанию звук играет на компьютере: мост на ТВ перехватывает `play()/pause()` звуковых элементов таймера
  и шлёт команды в консоль, та играет те же mp3. Режим хранится в `.state.json`.
- Chrome запускается с `--autoplay-policy=no-user-gesture-required`; на случай другого браузера звуки
  разблокируются по первому клику/клавише в окне терминала.

## Производительность Chromecast 1
- Сброс таймера давал заминки до ~1 с: `mask` на 3D-слоях переворота слишком тяжёл для его GPU.
  В `bridge.js` (только для ТВ) маска заменена на `clip-path` — вид тот же (отличия в 1 px сглаживания), заминка ≈170 мс.
- Пробовали и измеряли на самом ТВ; замер кадров (rAF) в постоянной версии убран — он сам нагружал слабое устройство.

## Зависания
- ТВ шлёт пульс раз в 10 с; `start.js` пишет предупреждение, если пульса нет 40 с.
- `cast.js` теперь отвечает PONG на пульс Chromecast (раньше молчал — Chromecast мог считать отправителя мёртвым).
- Пока причина единичных зависаний не установлена; при повторе смотреть окно Terminal с логом.

## Вывод таймера (`config.json`)
- `"output": "local"` — таймер окном Chrome на весь экран второго дисплея (`"display"` — его имя в macOS, сейчас `Waveshare-625`);
  `"chromecast"` — на Chromecast; `"both"` — на оба. Терминал всегда на главном экране.
- **Панель Waveshare 6.25" (720×1560) + Chromecast 1: работает только через HDMI-матрицу/разветвитель (проверено: Orei 8K 4×2).**
  Напрямую — чёрный экран. Причина установлена по совокупности признаков (не по прямому замеру): HDCP. Chromecast шифрует HDMI,
  панель и USB-захват MS2109 HDCP не поддерживают (телевизор — поддерживает и показывает). Настройки Chromecast
  (`hdmi_prefer_50hz`, `hdmi_prefer_high_fps`, 4 сочетания с перезагрузкой) на результат не влияли; root на прошивке 1.36 невозможен
  (HubCap закрыт с сборки 19084). Переходник «извлекатель звука» дал заставку, но с морганием; матрица решила проблему полностью.
  Ни программно, ни через USB HDCP не обойти: обмен идёт по линиям HDMI, USB Chromecast 1 — только питание.
- Режим `local` (таймер окном Chrome на панели, подключённой к Маку) остаётся запасным вариантом.
- Нужно, чтобы дисплей был **расширенным**, а не зеркальным (Системные настройки → Мониторы → «Использовать как»).
  Поворот (90°/270°) делает macOS, программе он не нужен: она берёт размеры экрана из системы.
- Окно позиционируется по координатам экрана (JXA `NSScreen`, пересчёт в верхний левый угол для Chrome).
